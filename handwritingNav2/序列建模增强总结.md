## 📝 具体改进内容

### 1. **添加位置编码模块**

```python
class PositionalEncoding(nn.Module):
    """
    位置编码 - 参考flodiff设计
    使用sin/cos函数为序列中的每个位置添加位置信息
    """
    def __init__(self, d_model: int, max_seq_len: int = 10):
        pos_enc[:, 0::2] = torch.sin(pos * div_term)
        pos_enc[:, 1::2] = torch.cos(pos * div_term)
```

**作用**: 让Transformer能够区分序列中的不同位置

---

### 2. **添加Transformer序列编码器**

```python
# 完整的Transformer编码流程
if self.use_transformer_encoder:
    # 1. 位置编码
    self.positional_encoding = PositionalEncoding(...)
    
    # 2. Transformer编码器层
    encoder_layer = nn.TransformerEncoderLayer(
        d_model=obs_dim,
        nhead=4,  # 4个注意力头
        dim_feedforward=4 * obs_dim,  # 前馈网络
        activation="gelu",
        batch_first=True,
        norm_first=True
    )
    
    # 3. 堆叠多层Transformer
    self.sequence_encoder = nn.TransformerEncoder(
        encoder_layer, 
        num_layers=2  # 2层
    )
```

**关键参数**:
- `context_size`: 5 - 历史观察帧数（与flodiff一致）
- `mha_num_attention_heads`: 4 - 注意力头数
- `mha_num_attention_layers`: 2 - Transformer层数
- `mha_ff_dim_factor`: 4 - 前馈网络维度因子

### 3. **改进观察编码流程**

```python
def encode_observations(observations):
    # ... 多模态特征融合 ...
    encoded_features = feature_fusion(combined_features)  # [B, obs_dim]
    
    # 序列建模增强（新增）
    if self.use_transformer_encoder:
        # 扩展为序列
        obs_sequence = encoded_features.unsqueeze(1)  # [B, 1, obs_dim]
        
        # 应用位置编码
        obs_sequence = self.positional_encoding(obs_sequence)
        
        # Transformer编码
        sequence_encoding = self.sequence_encoder(obs_sequence)
        
        # 平均池化聚合（参考flodiff）
        encoded_features = torch.mean(sequence_encoding, dim=1)
    
    return encoded_features  # [B, obs_dim]
```

## 🔧 新增配置参数

### train_diffusion_hwnav.yaml

```yaml
RL:
  DIFFUSION:
    # 动作序列长度（可配置）
    horizon: 16  # len_traj_pred，可调整
    
    # 序列建模增强配置（新增）
    context_size: 5                  # 历史观察帧数
    use_transformer_encoder: True    # 启用Transformer
    mha_num_attention_heads: 4       # 注意力头数
    mha_num_attention_layers: 2      # Transformer层数
    mha_ff_dim_factor: 4             # 前馈网络维度因子
```

### 配置说明

| 参数 | 默认值 | 作用 | 调优建议 |
|------|--------|------|----------|
| `horizon` | 16 | 动作序列长度 | 简单任务用8，复杂任务用24-32 |
| `context_size` | 5 | 历史帧数 | 3-8，更多历史需要更多内存 |
| `use_transformer_encoder` | True | 是否启用 | 禁用可加速但损失性能 |
| `mha_num_attention_heads` | 4 | 注意力头数 | 2/4/8，更多头学习更多模式 |
| `mha_num_attention_layers` | 2 | Transformer层 | 1-4，更深网络更强但更慢 |
| `mha_ff_dim_factor` | 4 | 前馈维度因子 | 2-8，影响表达能力 |
